## 1. Where the HUD is called from

The race frame routine (obj1+0x1fd8c, race.frame-calls) calls `obj1+0x1a92c` (main HUD drawer) at obj1+0x208ed and the held-item icon routine `obj1+0xdd8` at obj1+0x208f7, both after the object pass `obj1+0x161fc` (obj1+0x208f2) and right before the page flip `obj1+0x27de0` (obj1+0x208fc; it writes the CRTC start address 0x0c/0x0d from `[0x28b24]` and waits for retrace). So HUD is drawn over the finished 3D frame, every frame. `obj1+0x2f80` (static HUD, called once from obj1+0x367a at race start) draws the fixed label panels. `obj1+0x19e0c` (lap-event screen) is called from the frame routine only at lap/finish events (obj1+0x214f2, +0x2195d, +0x22579).
Cites: `WW.EXE:obj1+0x208ed fp=bed06508`, `WW.EXE:obj1+0x208f7 fp=4d3e67e3`, `WW.EXE:obj1+0x367a fp=bf674ec5`, `WW.EXE:obj1+0x22579 fp=f00c67ed`. Confidence: high (call order read), meaning of each call as HUD high.
