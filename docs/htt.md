# HTT — default race scores

wac1.htt/wac2.htt initialize wacky1.hi/wacky2.hi. Identical [HI layout](hi.md), stored inside WACKY.DAT.

## Verification notes

- [PROVEN] (`score-files`, `score.defaults`): `WAC1.HTT` and `WAC2.HTT` are byte-identical, 6624 bytes, and the installed `WACKY1.HI` equals them.
