# POS — wrong-way grid

64×64 16-bit progress values. Moving toward smaller values triggers wrong-way warnings.

## Verification notes

Local observation: every POS member here is 8194 bytes, two more than 64×64×2. The wiki does not explain those extra bytes or explicitly specify endianness; do not assume a header placement.
