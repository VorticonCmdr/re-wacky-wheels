# ING — WACKY.ING auxiliary data

66-byte unknown prefix followed by apparently unused 46-byte score-like records. At least 28 prefix bytes are needed for startup; offsets 0x14/0x18 affect memory allocation.

## Verification notes

Local observation: 1170 bytes; (1170−66)/46=24 records. Prefix semantics and field widths are not independently established.
