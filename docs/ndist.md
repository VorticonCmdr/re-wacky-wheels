# NDIST — projection table

Wiki: INT16LE table; plotting 70 values/row yields parabola-like columns. Values influence object placement by viewing angle.

## Verification notes

Local observation: 89600 bytes. Initial bytes 85 00 00 00 86 00 00 00 resemble 32-bit values. This does not verify a corrected schema.
