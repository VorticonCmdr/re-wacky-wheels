# OTT — default trial records

wac1.ott/wac2.ott initialize wacky1.tim/wacky2.tim. Identical [TIM layout](tim.md), stored inside WACKY.DAT.

## Verification notes

- [PROVEN] (`score-files`, `tim.layout`): the defaults `WAC1.OTT` and `WAC2.OTT` (12 and 6 horsepower) are 3600-byte time tables of the layout in [tim.md](tim.md); `WACKY1.TIM` equals `WAC1.OTT`.
