Before racing

Surface painting uses the original tile properties. The wrong-way progress grid and preview image stay as supplied. Major layout changes need those updated before playing in DOS.

Quick controls

Scroll to zoom. Space + drag to pan. Alt + click to pick a tile. Delete removes a selected object or waypoint.

Route: drag a node to move it; click elsewhere to insert one into the nearest segment. Object: choose one in the palette, then click to place it or drag an existing marker.

Make yourself at home

Choose a track, pick a tile in the palette, and drag on the map. One stroke is one undo step.

Drafts save in this browser when storage is available. Save project downloads a portable draft; reopen it with the same original archive. Export edited DAT includes changes across every edited track. It downloads a new archive, leaving your source files untouched.

The editor preserves unknown fields, original object attributes, and all untouched archive assets. Wrong-way grids, collision masks, and thumbnail previews are not regenerated. The playable browser port is still to come.
