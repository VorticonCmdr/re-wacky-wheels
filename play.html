Display

How the finished picture is put on the screen, for the Original and the Enhanced graphics alike; the picture itself is not changed. The default is 4:3, the shape the game had on a monitor; with square pixels, fit, no CRT look and the HUD in the picture the browser scales the picture itself, as the page always did. The HUD layer draws the HUD, the map and the in-race menu over the CRT look, crisp or smoothed. Otherwise fit fills the space and draws a pixel's edge soft where it falls between screen pixels, and whole screen pixels gives every picture row the same number of screen rows (with square pixels every column too). The DOS monitor's 4:3 makes each pixel 1.2 times as tall as wide. The CRT look adds scanlines, glow and a curved tube. Double-click the picture for full screen; Esc leaves it. The same settings are in the game's menu: GAME OPTIONS, DISPLAY AND EFFECTS, DISPLAY OPTIONS.

Graphics

Original is the reference renderer. Enhanced keeps the original artwork and resolution and adds smooth motion between the game's 11 ticks a second, shadows, skid marks, particles, moving water, fog, clouds and a far range behind the horizon, and track lighting: presentation only, the race runs the same either way. The same settings are in the game's menu: GAME OPTIONS, DISPLAY AND EFFECTS.

Arrows steer, Alt (or Up, A) accelerates, Down (or Z) brakes, Space is the hand brake turn, Ctrl fires a hog or drops the held item (not ported yet), R restarts the race.
